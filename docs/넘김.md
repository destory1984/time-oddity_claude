## 2. 정한 것

- 주인공 이름은 소라다. 기획서 원문의 "서라"는 모두 고쳤다.
- 소라는 1권의 도트 그림을 그대로 쓴다. `LICENSE` 는 두 갈래다: 코드와 문서는 MIT, 소라는 권리 유보.
- 그림은 직접 그리지 않고 발주서를 써서 챗GPT에 맡긴다. 사용자가 2026.10.7에 외주를 넉넉히 써도 된다고 했다. 주문은 `tools/art-order.sh` 로 Codex CLI에 바로 넣는다. 화면 어림의 땅 그림만 임시로 그린 것이다.
- 다이얼은 해 다이얼 1개다. 한 칸(12픽셀)에 꼭 1년. 사건이 있는 해에 멈추면 그날에 걸린다.
- 굴렸다 놓으면 1.5초쯤에 걸쳐 느려지다 눈금에 선다. 눈금마다 소리가 난다. 소리의 중심은 1,200Hz, 10칸째는 760Hz.
- 날 단위는 "하늘로 날짜 맞히기" 놀이 안에서만 쓴다. 날 다이얼을 따로 두지 않는다.
- 먼 시대는 다이얼로 가지 않고 수첩에서 칸을 눌러 간다.
- **2권은 1권과 별개의 게임이다.** 저장을 따로 쓰고, 1권을 하지 않아도 할 수 있다. 코드는 이 저장소에 새로 짓고, 1권에서 쓸 것은 베껴 온다. 이야기는 1권 뒤를 잇는다.
- 여는 쪽에서 놋쇠 다이얼을 보여 준다. 메모는 화면 메모(25자)와 수첩 메모(60자)로 나눈다. 할머니 메모는 가기 전에도 보인다. 한 번 가 본 칸은 "가기"가 땅까지 바로 데려다준다. 놀이 둘은 날짜가 하루까지 적힌 칸 모두(70개쯤)에 붙인다.
- 첫 칸까지는 5분 반이다. 다이얼, 날기, 내려앉기, 하늘 보기, 오늘로를 차례로 가르치고, 사진과 엽서는 두 번째 칸에서 가르친다. 여는 쪽은 1권의 일을 말하지 않는다.
- 첫 토막: 날지 않는다. 지구본을 손가락으로 돌려 점을 누르면 그 칸에 선다. 칸은 1(대피라미드), 39(콜럼버스의 월식), 64(수정궁), 82(12초의 비행) 넷이다. Vite와 Babylon.js로 짓고, 땅 그림은 임시로 그린다. 날기는 다음 토막이다.
- **볼 것이 있는 곳은 화면에 표시한다.** 사용자: "뭐가 있는지 모르니까, 계속 돌리기만 해", "우린 역사학자를 대상으로 하는게 아니라구"(2026.10.7). 다이얼에 금색 표시와 끝의 딱지를 넣었고, 눌러서 간다. `상세-기획-2` 4.1절.
- 하늘 계산은 astronomy-engine(MIT, 브라우저용 114KB)으로 한다. 기원전 2560년까지 달, 행성, 일식, 월식, 세차운동이 문헌과 맞았다. 별 목록, 혜성, 초신성은 따로 넣어야 한다.
- 1969년 이웃집 마당은 어두운 마당 그대로 두고, 때는 7월 21일 밤 9시쯤(재방송을 보는 저녁)으로 잡는다. 서쪽 하늘에 계산한 초승달이 뜨고, 두 사람은 아직 달 위에 있다. 처음에는 사실(첫 발은 한국 시각 한낮)과 달라도 게임이니까 괜찮다고 정했다. 사실과 조금 어긋나는 연출은 사용자가 받아들일 수 있다는 뜻이다. 다만 날짜, 자리, 남은 것은 여전히 실제여야 한다.

## 3. 아직 정하지 않은 것

1. **다이얼의 생김새.** 큰 호(아래)와 세로 띠(오른쪽) 가운데 하나. 둘은 움직임과 소리가 같다. 사용자는 "다이얼(큰 호)이 나아 보인다"고 했고, 다른 사람의 의견을 모으는 중이다.
2. **`상세-기획-2-칸-하나의-흐름.md` 6절의 물음 5개.** 첫 토막을 만져 보면 답이 나온다. 지금 정하지 않아도 된다.
3. **첫 토막을 사용자가 손전화로 만져 보고 할 말.** "오늘로"의 3초가 알맞은가, 다이얼과 하늘 보기가 손가락끼리 부딪치는가, 위로 밀면 고개를 드는 방향이 맞는가, 소리가 어떤가, 받은 그림 8장의 그림체가 좋은가.
4. **여는 쪽의 쪽지 글.** `상세-기획-1.md` 2.3절의 쪽지 세 토막은 초안이다. 사용자가 읽고 고쳐야 한다.

## 4. 찾아낸 사실 문제

기획서를 고치거나 원 자료로 확인해야 한다.

- 수정궁은 1852년에 하이드파크에서 헐려 시드넘으로 옮겨졌고, 1936년에 불탄 곳은 시드넘이다. 기획서 7절과 12절은 하이드파크에서 1936년에 사라진다고 적었다.
- 암스트롱이 달에 발을 디딘 때는 한국 시각 1969.7.21 오전 11시 56분이다. 기획서 8절의 "어두운 마당"과 맞지 않았다. **장면의 때를 그날 밤 9시쯤으로 잡아 풀었다(2026.10.7).** 그날 저녁의 재방송과 달을 떠난 시각(한국 시각 22일 02:54)은 확인해야 한다.
- 기획서 4절은 메모를 25자라 했는데, 6절의 본보기 메모는 55자다. `상세-기획-1.md` 5.1절에서 화면 메모와 수첩 메모로 나누자고 했다.
- 이 셋은 기억에 기대어 짚은 것이다. 원 자료로 확인하지 않았다.
- 탈레스의 일식(칸 7)은 그 자리에서 오후 5시 반쯤, 해의 높이 17도였다. 이것은 계산한 값이다. 기획서 4절과 `상세-기획-1.md` 5.2절의 "한낮"을 "해 질 녘"으로 고쳤다(2026.10.7).

## 6. 일하는 법

- 화면을 그림 파일로 찍을 때는 크롬을 머리 없이 띄운다. `ui-samples.html#s3`, `mock-screens.html#s2` 처럼 주소 끝에 번호를 붙이면 한 장만 보인다.

```bash
chrome --headless=new --hide-scrollbars --allow-file-access-from-files --window-size=395,832 --virtual-time-budget=6000 --screenshot=docs/mock/screen-2.png "file:///<저장소 경로>/docs/mock-screens.html#s2"
```

- 눈에 띄는 일을 하나 마치면 `docs/바뀐-것들.md` 의 그날 맨 위에 한 줄을 더하고, 같은 커밋에 넣는다. 적는 법은 그 파일 위에 있다.
- 게임을 고치면 `npm test`, `npm run build` 를 돌리고 `play/` 까지 함께 커밋한다. Pages는 `play/` 를 그대로 내보낸다.
- 화면은 앱 안의 브라우저 창으로 본다(`.claude/launch.json` 의 `time-oddity`, 포트 4318). 주소 끝에 `#shot=crystalPalace,sky` 나 `#go=khufu` 를 붙이면 그 장면에서 시작한다.
- 푸시한 뒤 Pages에 반영되기까지 40초쯤 걸린다.
- 깃허브에 올리기 전에 매번 사용자에게 묻는다.
