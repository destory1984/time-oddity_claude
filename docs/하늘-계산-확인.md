# 하늘 계산 확인: 기원전까지 셈할 수 있는가

- 한 날: 2026.10.7
- 무엇을 확인했나: 기획서 14절 1번과 `상세-기획-1.md` 4.3절 1번. 그날의 하늘을 기원전까지 계산할 수 있는가.
- 답: **된다.** astronomy-engine 2.1.19(MIT) 하나로 기원전 2560년까지 달, 행성, 일식, 월식, 세차운동을 셈할 수 있다.
- 돌려 본 것: `tools/sky-check.mjs`. 다시 돌리는 법은 그 파일 맨 위에 있다.
- 한계: Node 24에서 돌렸다. 브라우저에서 열어 보지는 않았다. 브라우저용 파일(`astronomy.browser.min.js`, 114KB)은 같은 코드다.

## 1. 알려진 값과 견준 것

계산이 맞는지 보려고, 문헌에 값이 남아 있는 사건 일곱 개를 셈해 견주었다. "문헌" 칸은 기억에 기댄 값이다.

| 사건 | 계산한 값 | 문헌 | 맞는가 |
|---|---|---|---|
| 탈레스의 일식 | 기원전 585.5.28(율리우스력), 개기, 가장 깊은 때 13:36 UT | 같은 날, 개기 | 맞음 |
| 기원전 7년 목성과 토성의 세 번 만남 | 5.28, 10.3, 12.4. 물고기자리 | 5.29, 9.29 → 10.1, 12.4 → 12.5 | 맞음(가운데 것만 2 → 4일 차이) |
| 1054.7.4 손님별의 새벽 | 달이 13% 남은 그믐달 | 새벽 하늘에 그믐달 | 맞음 |
| 콜럼버스의 월식 | 1504.3.1 00:40 UT(율리우스력 2.29 저녁), 개기 48분 | 00:41 UT | 맞음 |
| 갈릴레오의 목성 | 1610.1.7 목성이 황소자리 | 황소자리 | 맞음 |
| 쿡의 금성 일면통과 | 1769.6.3 19:16 → 6.4 01:35 UT | 같음 | 맞음 |
| 에딩턴의 일식 | 1919.5.29, 프린시페에서 개기, 14:15 UT | 같음 | 맞음 |

세차운동도 맞는다. 북극에서 투반까지의 거리는 기원전 2800년에 0.09도, 기원전 2500년에 1.62도다. 같은 때 지금의 북극성은 25도 떨어져 있다. 기획서 7절의 "스톤헨지의 북극성은 투반"은 그대로 쓸 수 있다.

## 2. 빠르기와 크기

- 하늘 한 장(해, 달, 행성 5개의 높이와 방위, 달 모양)을 셈하는 데 0.07밀리초다. 한 프레임 16밀리초의 200분의 1이라, 다이얼을 굴리는 동안 프레임마다 셈해도 된다.
- 브라우저용 파일은 114KB다.
- 기원전 10000년까지 넣어도 오류 없이 값이 나온다. 다만 그 값이 맞는지는 견줄 문헌이 없어 확인하지 못했다.

## 4. 칸에 넣을 달

`상세-기획-1.md` 에서 "계산 뒤 채움"으로 비워 둔 것들이다.

| 칸 | 때 | 달 |
|---|---|---|
| 45 열흘이 사라진 날 | 1582.10.4(율리우스력) 저녁 | 88% 찬, 기우는 달 |
| 45 열흘이 사라진 날 | 1582.10.15(그레고리력) 저녁 | 79% 찬, 기우는 달 |
| 64 수정궁 | 1851.5.1 | 삭. 달이 보이지 않는 날 |
| 82 12초의 비행 | 1903.12.17 아침 | 2% 남은 그믐달. 하루 뒤가 삭 |
| 쪽지 1969.7.21 | 한국 시각 오전 11:56 | 36% 찬 초승달 |

- 1582년 10월 4일과 15일 사이는 꼭 하루다. 요일은 목요일과 금요일이다. 달은 88%에서 79%로 하루치만 기운다. 칸 45의 "달은 달력을 모른다"가 숫자로 선다.
- 수정궁이 문을 연 날은 삭이다. "그날 달은" 자리에 "없음"이 들어간다. 남은 것도 "없음"인 칸이라 짝이 맞는다.

## 5. 계산하다 찾은 것

### 5.1 탈레스의 일식은 한낮이 아니다

할리스 강(북위 40도, 동경 35도)에서 일식이 가장 깊은 때는 15:09 UT, 그 자리 시각으로 오후 5시 반쯤이다. 해의 높이는 17도다. 해 지기 두 시간쯤 전의 늦은 오후다.

- `상세-기획-1.md` 5.2절의 화면 메모 "한낮에 해가 사라짐", 소라의 "낮인데 캄캄해", 장면의 "강가의 한낮"이 사실과 다르다. 기획서 4절의 "탈레스의 낮에 뜬 코로나"도 같다.
- 낮은 맞으니 소라의 대사는 그대로 써도 된다. "한낮"만 "해 질 녘"이나 "늦은 오후"로 고치면 된다. 해가 낮게 뜬 채 가려지는 그림이라 장면은 더 좋아진다.
- 그 자리에서 개기였는지는 계산으로 못 정한다. 강 가운데는 99.9% 가려짐, 강 어귀(북위 41.7도)는 개기로 나왔다. 2,600년 전 지구 자전의 어긋남(ΔT 18,468초)에 몇 백 초의 불확실함이 있고, 그만큼 개기의 띠가 동서로 밀린다. 싸움터의 자리도 알려져 있지 않다. 게임에서는 개기로 그려도 틀렸다고 할 수 없다.
- 강을 따라 열한 곳을 다시 셈했다(2026.10.7, 칸을 넣으면서). 가려진 넓이는 아바노스 96.2%, 크르셰히르 굽이 97.4%, 키르칼레 98.6%, 칼레직 99.3%이고, 찬크르 굽이부터 강어귀까지는 모두 100%다. 다 가려진 동안은 찬크르 141초, 오스만즉 223초, 카르그 227초, 보야바트 231초, 바프라 199초, 강어귀 175초다. 칸은 오스만즉 여울(북위 40.97, 동경 34.80)에 세웠다. 가장 깊은 때는 15:08 UT, 그 자리 시각 오후 5시 28분, 해의 높이 17.6도, 방위 282도다. 해가 파이기 시작하는 것은 그 61분 전이다.
- 그때 해 위쪽 하늘에 수성(높이 30도), 목성(29도), 화성(41도)이 있다. 금성은 땅 아래다.

### 5.2 1969.7.21 서울의 하늘

| 때(한국 시각) | 무슨 일 | 해의 높이 | 달의 높이 |
|---|---|---:|---:|
| 05:17 | 착륙 | -1.7도 | -56.9도 |
| 05:27 | 해 뜸 | | |
| 11:35 | 달 뜸 | | |
| 11:56 | 첫 발 | 70.6도 | 3.3도 |
| 19:50 | 해 짐 | | |
| 23:08 | 달 짐 | | |

- 착륙한 새벽에는 달이 땅 아래에 있다. 마당은 어둡지만 하늘 칸에 달이 없다.
- 첫 발을 디딘 때에는 달이 뜬 지 21분 되었다. 한낮이라 보이지 않는다.
- **그날 저녁 8시 → 11시에는 어두운 서쪽 하늘에 초승달이 떠 있다.** 그리고 두 사람은 아직 달 위에 있다. 달에서 떠난 때가 7월 22일 오전 2시 54분(한국 시각)이기 때문이다(기억에 기댄 값, 확인할 것).
- 그래서 장면을 "7월 21일 밤 9시쯤, 재방송을 보는 마당"으로 잡으면 넷이 한꺼번에 맞는다. 어두운 마당(사용자가 정한 것), 날짜 7.21, 계산한 하늘의 달, 소라의 대사 "저 달에 지금 사람이 있는 거야?". 그날 저녁에 재방송이 있었는지는 그날 신문으로 확인해야 한다.

### 5.3 콜럼버스의 월식은 초저녁이다

가장 깊은 때는 자메이카 시각으로 2월 29일 저녁 7시 반쯤이고, 달의 높이는 19도다. 개기는 48분 이어졌다. 동쪽 하늘에 낮게 뜬 붉은 달이라, 만과 배의 실루엣 위에 그리기 좋다.

## 6. 만들 때 지킬 것

- 날짜 변환은 한 곳에서만 한다. 역사 연도(0년 없음, 기원전 585년)와 천문 연도(0년 있음, -584년), 율리우스력과 그레고리력을 모두 율리우스일(JD)로 바꾼 뒤 라이브러리에 넘긴다. 자바스크립트의 `Date` 는 기원전에도 그레고리력을 거꾸로 늘여 쓰므로, 1582.10.15 앞의 날짜에 `Date` 를 그대로 쓰면 틀린다.
- 달 모양과 행성 자리는 ΔT의 불확실함을 거의 타지 않는다. 일식이 땅의 어디에서 보였는가만 탄다. 기원전의 일식 칸(7번)에서만 조심한다.
