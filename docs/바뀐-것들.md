# 바뀐 것들: 날마다 한 일

나중에 게임 안에 "바뀐 것들" 쪽을 만들 때 쓸 자료다. 우주 한량(1권)의 `src/core/changes.js` 와 같은 쓰임이다. 사용자가 2026.10.7에 남겨 두라고 했다.

## 적는 법

- 한 줄에 하나, 쉬운 말로 적는다. 새 날이 위에 오고, 같은 날 안에서도 새 줄이 위에 온다.
- 줄은 게임에 그대로 들어갈 글이라 "습니다"로 끝낸다.
- 게임이 생기기 전(지금)에는 무엇을 정하고 만들었는지를 적는다. 게임이 생긴 뒤에는 1권처럼 화면에 보이거나 귀에 들리는 것만 적는다. 새로 할 수 있는 것, 새로 보이는 것, 고친 잘못은 적고, 단추 자리 옮기기나 글 다듬기는 적지 않는다.
- 숫자를 넣는다. 사실 확인으로 고친 것은 무엇이 무엇으로 바뀌었는지 적는다.
- 눈에 띄는 일을 하나 마치면 그날 맨 위에 한 줄을 더한다. 커밋할 때 함께 넣는다.
- 게임 코드가 생기면 이 표를 `src/core/changes.js` 의 `{ day, text }` 목록으로 옮기고, 그 뒤로는 거기에 적는다.
