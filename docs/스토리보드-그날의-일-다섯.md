# 스토리보드: 그날의 일로 다시 짓는 다섯 곳

2026.10.22. 직지 견본을 보고 사용자가 "몇 곳만 먼저"를 골랐다. 옛 꼴(심부름, 물건 전하기, 찾기)로 남은 마흔두 곳 가운데 사람이 많이 찾을 다섯을 먼저 직지, 달링턴, 런던 꼴로 다시 짓는다. 다 지으면 나머지를 다시 묻는다.

다섯 곳 모두 장면, 장면 이름, 사람 그림은 그대로 쓴다. 새 그림이 필요한 곳은 콜로세움 하나다(차양 그림 한 장, 없이 갈 길도 적었다). 놀이 꼴은 한 자리 안에서 겹치지 않게 했다. 대사는 모두 25자 안팎의 온전한 문장이고, 지나온 장면으로 되돌려 보내는 말은 없다.

| 자리 | 1단계 | 2단계 | 3단계(보여 주는 그림) | 막는 곳 |
|---|---|---|---|---|
| 로마 콜로세움 (AD 80) | 시장: 빵에 여덟 쪽 금 긋기 (aim) | 광장: 세 사람의 문 번호 읽어 주기 (round) | 경기장 안: 뱃사람과 차양 줄 당기기 (mash, 새 그림 `show-awning`) | 광장 → 경기장 안 |
| 프랑스 파리 에펠탑 (1889) | 입구: 표 끊기 (beat) | 탑 아래: 사진에 들 사람 셋 모으기 (round) | 기계관: 축음기 바늘 놓기 (aim, `show-phonograph`) | 입구 → 탑 아래 |
| 이집트 기자 쿠푸 왕의 피라미드 | 나루: 지렛대로 배의 돌 내리기 (aim) | 일꾼 마을: 원뿔 빵 굽기 (fill) | 피라미드 발치: 박자 맞춰 썰매 끌기 (beat, `show-sled`) | 마을 → 발치 |
| 조선 한양 훈민정음 (1446) | 저잣거리: 방 붙이기 (mash) | 광화문 앞: 세 사람에게 새 글자 읽어 주기 (round) | 집현전 뜰: 책을 실로 묶기 (aim, `show-letters`) | 광화문 → 집현전 뜰 |
| 인도 아그라 타지마할 | 강가: 코끼리와 큰 돌 끌기 (beat) | 마당: 꽃잎 돌 갈기 (aim) | 무덤 위: 꽃잎 박기 (fill, `show-flower`) | 마당 → 무덤 위 |

## 로마 콜로세움 (AD 80)

경기장 문이 처음 열리는 날, 소라가 시장에서 빵에 금을 긋고, 광장에서 문 번호를 못 읽는 사람들에게 번호를 읽어 주고, 경기장 안에서 뱃사람들과 차양 줄을 당겨 그늘을 편다.

- `first`: 오늘은 콜로세움이 처음 문을 여는 날이란다. 잔치가 잘 열리도록 도와주렴.
- `ask`: 새 경기장이 여는 날, 무엇을 도울까?
- `gate`: 광장(plaza), 2단계를 마칠 때까지. 소라: "경비병이 줄을 막고 있어. 아직 못 가."
- `done`: 빵에 금을 긋고, 문 번호를 읽어 주고, 차양 줄을 당겼다.
- `reply`(생선 소스와 토가 이야기를 바꾼다): 그 큰 천을 뱃사람들이 돛처럼 다뤘단다. 네 손도 보탰구나.
- 해 보기(생선 소스, 겨울잠쥐, 눈, 토가, 식초 물, 입장 조각, 물시계, 볶은 콩)와 티투스, 행진 자리는 그대로 둔다.

| | 1 시장 거리 (aim) | 2 광장 (round) | 3 경기장 안 (mash) |
|---|---|---|---|
| 누구 | `baker` 빵 장수 | `wife`, `old`, `child` | `sailor1` 뱃사람 |
| 대사 | 반죽에 여덟 쪽 금을 그어야 해. / 손님이 몰려와요. 같이 그어 줄래요? | wife: 조각에 새긴 번호를 못 읽겠구나. / 열다섯이라고? 아, 저쪽 문이구나. old: 눈이 어두워 번호가 안 보여. / 서른여덟이라고? 저기로 가야겠군. child: 내 조각도 봐 줘. 스물셋이야? / 엄마도 스물셋이랬어. 거기 갈래! | 해가 높아졌소. 차양을 펴야 하오. / 줄을 같이 당기겠소? 영차! |
| 셈 | 빵 {all}개 가운데 {n}개에 금을 그었다. | 조각 {all}개 가운데 {n}개의 번호를 읽어 주었다. | 차양 줄 {all}개 가운데 {n}개를 당겼다. |
| 잘함 / 못함 | 반듯하게 그었어! / 앗, 금이 비뚤어졌어! | | 영차! 천이 펴졌어! / 앗, 줄이 미끄러졌어! |
| 뒷말 | boy: 빵 받았다! 주인님께 뛰어가야지. | guard: 번호를 다 읽었구먼. 들어가시오. | sailor2: 그늘이 졌소. 관중들이 좋아하오. clap: 황제가 나무 공을 던진다! |

- 곁말: maid, reader(S0, 빵집 일손이 모자람), guard, ticket(S1, 번호를 못 읽는 이가 많음), usher, nuts(S2, 해가 뜨거움), clap, cheer(S3, 그늘이 시원함).
- 그림: 차양을 보여 줄 새 그림 `rome/show-awning.webp` 한 장이 있어야 한다(경기장 위에 편 천과 줄). 받지 않으려면 3단계에서 있는 `show-balls`(나무 공)를 쓸 수 있으나, 한 일(차양)과 그림(공)이 어긋난다.
- 찾아본 것: 입구 아치 위 문 번호를 새기고 빨갛게 칠함(Smithsonian), 80개 문 가운데 관중 문 76개, 티투스가 나무 공을 던짐(카시우스 디오 66.25).
- 기억으로 쓴 것: 미세눔 함대 뱃사람이 차양을 다룸, 입장 조각에 로마 숫자 문 번호, 폼페이의 여덟 쪽 빵, 글 모르는 사람이 많음, 잔치가 백 날.
- 지어낸 것: 빵이 모자란 일, 경비병이 줄을 막은 일, 15, 38, 23이라는 번호, 그 시각에 차양을 편 일, 모든 대사.

## 프랑스 파리 에펠탑 (1889)

탑에 처음 사람이 오르는 날, 소라가 입구에서 표를 끊고, 탑 아래에서 사진사를 도와 사람을 모으고, 기계관에서 말하는 기계의 바늘을 놓아 노래를 들려준다.

- `seek`(장면마다 셋을 찾아야 넘어가는 것)을 뺀다. 그날의 일과 함께 둘 수 없다. 찾기 아홉의 누를 곳과 메모(돔, 깃발, 꼬마 기차, 계단, 신문, 엽서, 다리, 플라이휠)는 볼거리로 남긴다.
- `first`: 오늘은 에펠탑에 처음 사람들이 오르는 날이란다. 박람회 일을 도와주렴.
- `ask`: 말하는 기계에서는 무슨 소리가 날까?
- `gate`: 입구(gate), 1단계를 마칠 때까지. 소라: "입구 줄이 꽉 막혔어. 표부터 끊자."
- `done`: 표를 끊고, 탑 앞에서 사진을 찍고, 말하는 기계로 노래를 들려주었다.

| | 1 박람회 입구 (beat) | 2 에펠탑 아래 (round) | 3 박람회 기계관 (aim) |
|---|---|---|---|
| 누구 | `ticket` 표 파는 사람 | `kid`, `painter`, `postcard` | `phono` 말하는 기계 지기 |
| 대사 | 오늘은 탑이 열려 줄이 끝이 없소. / 표 끊는 걸 좀 거들어 주겠소? | kid: 사진을 찍는대? 나도 들어갈래! / 아빠, 나 탑 앞에 서 있을게. painter: 사진이라. 그림보다 빠르긴 하지. / 좋소, 붓을 놓고 잠깐 서 주리다. postcard: 어머, 탑 앞에서 사진이라니요. / 엽서를 들고 서 있을게요. | 줄 선 손님이 많아 손이 모자라오. / 통이 돌 때 바늘을 첫머리에 놓아 주오. |
| 셈 | 표 {all}장 가운데 {n}장을 끊었다. | 사진에 들 {all}명 가운데 {n}명이 모였다. | 노래를 {all}번 가운데 {n}번 들려주었다. |
| 잘함 / 못함 | 딸깍! 한 분 들어가요! / 앗, 표가 비뚤게 찢겼어! | | 노래가 나와! 손님이 웃어. / 앗, 노래 중간부터 나와! |
| 뒷말 | parasol: 줄이 줄었구나. 이제 들어가 보자. | photo: 움직이지 마시오! 찰칵, 다 찍혔소. | queue: 세상에, 통에서 사람 목소리가 나네. |

- 곁말: news, tophat(S0, 표 끊는 이가 하나뿐), photo, stairs(S1, 사진사가 사람을 찾음), engineer, queue(S2, 줄이 한 시간째), reporter(S3, 내일 신문에 나옴).
- 그림: 있는 `paris/show-phonograph.webp`. 새 그림은 없다.
- 찾아본 것: 탑 위 르 피가로 인쇄(1889.5.15), 엘리베이터 없던 첫 주에 29,922명이 걸어 오름, 층마다 우체통, 꼬마 기차, 테아트로폰.
- 기억으로 쓴 것: 이날 탑이 처음 열렸다는 것, 에디슨 축음기가 나와 관을 귀에 대고 들었다는 것, 그 무렵 사진은 잠깐 움직이지 않아야 찍혔다는 것, 박람회 축음기는 전기로 돌았다는 것(그래서 "태엽 감기" 대신 "바늘 놓기").
- 지어낸 것: 소라가 표를 끊는 일, 표 끊는 이가 하나뿐, 셋을 세워 찍는 사진, 바늘 놓기, 모든 대사.

## 이집트 기자 쿠푸 왕의 피라미드

소라가 나루에서 배의 흰 돌을 지렛대로 내리고, 일꾼 마을에서 썰매 끄는 조가 먹을 원뿔 빵을 굽고, 피라미드 발치에서 줄 끄는 일꾼들과 박자를 맞춰 썰매를 끌어 돌을 비탈길로 올린다. 돌 조각을 들고 가는 심부름은 뺀다.

- `first`: 큰 피라미드를 한창 쌓는 중이란다. 피라미드가 잘 올라가도록 도와주렴.
- `ask`(그대로): 돌은 어떻게 저 위로 올라갈까?
- `gate`: 일꾼 마을(village), 2단계를 마칠 때까지. 소라: "우두머리가 썰매 길을 막고 있어. 못 가."
- `done`: 돌을 내리고, 빵을 굽고, 썰매를 끌어 돌을 올렸다.
- `reply`(메레르의 일지 이야기)와 `deep`(카메라와 몸짓)은 그대로 둔다.

| | 1 나루 (aim) | 2 일꾼 마을 (fill) | 3 피라미드 발치 (beat) |
|---|---|---|---|
| 누구 | `hauler` 돌 내리는 일꾼 | `baker` 빵 굽는 아주머니 | `puller` 줄 끄는 일꾼 |
| 대사 | 투라에서 온 흰 돌을 내려야 한단다. / 지렛대를 같이 눌러 보련? | 썰매 끄는 조가 먹을 빵이 모자라. / 빵틀을 숯불에 묻어 같이 굽자꾸나. | 빵을 먹었으니 힘이 나는구나. / 물을 부으면 다 같이 끄는 거야. |
| 셈 | 돌 {all}개 가운데 {n}개를 내렸다. | 빵 {all}틀 가운데 {n}틀을 구웠다. | 썰매를 {all}번 가운데 {n}번 함께 끌었다. |
| 잘함 / 못함 | 쿵! 돌이 굴림대에 앉았어! / 앗, 돌이 기우뚱해! | 노릇노릇 잘 구워졌어! / 앗, 겉이 탔어! | 영차! 썰매가 쑥 나가! / 앗, 혼자 당겼어! |
| 뒷말 | merer: 세 개 내렸구나. 일지에 적어 두마. | foreman: 빵이 올라가니 썰매도 쉰다. 지나가거라. | pourer: 물을 부으니 잘 미끄러지지? scribe: 들어온 돌 하나, 적어 두었다. |

- 곁말: rower, merer(S0), foreman(S0, S1), kid(S1), waterboy(S2), ankhhaf, merer(S3).
- 그림: 있는 `giza2560/show-sled.webp`. 돌 조각 그림 `thing.webp` 는 쓰지 않게 된다(지울지 묻는다).
- 찾아본 것: 메레르의 일지(투라의 흰 돌을 배로 나름), 배 한 척에 돌 서른 개쯤, 일꾼 마을의 빵 굽는 곳과 빵틀(그 마을이 쿠푸보다 뒤라는 말도 있다), 안크하프, 모래에 물을 부으면 끄는 힘이 절반.
- 기억으로 쓴 것: 지렛대와 굴림대로 돌을 내림, 원뿔 빵틀을 숯불에 묻어 구움, 조가 줄을 함께 끎.
- 지어낸 것: 그날 빵이 모자란 일, 빵이 올라가면 썰매가 쉬어 길이 열린다는 것, 박자에 맞춰 끄는 것, 모든 대사.

## 조선 한양 훈민정음 (1446)

새 글자가 나온 해 가을, 소라가 저잣거리에서 방을 붙이고, 광화문 앞에서 세 사람에게 새 글자를 읽어 주고, 집현전 뜰에서 학사와 함께 책 "훈민정음"을 실로 묶는다.

- `first`: 새 글자 스물여덟 자가 세상에 나온 해란다. 새 글자를 널리 알리게 도와주렴.
- `ask`: 새 글자는 어떻게 세상에 나왔을까?
- `gate`: 광화문 앞(gate), 2단계를 마칠 때까지. 소라: "수문장이 대궐 문을 막고 있어. 못 가."
- `done`: 방을 붙이고, 새 글자를 읽어 주고, 책을 실로 묶었다.
- `reply`: 그때 묶은 책 한 권이 지금도 남아 국보가 되었단다.
- 할머니는 "날"이 아니라 "해"라고만 한다. 반포한 날에 무엇을 했는지는 기록이 거의 없어, 반포식이나 잔치는 그리지 않고 누구도 "오늘이 반포한 날"이라고 말하지 않는다. 세종은 말을 걸 수 없는 먼발치에만 둔다.

| | 1 저잣거리 (mash) | 2 광화문 앞 (round) | 3 집현전 뜰 (aim) |
|---|---|---|---|
| 누구 | `reader` 방 읽어 주는 선비 | `farmer`, `bearer`, `elder` (`official` 이 맡김) | `scholar` 집현전 학사 |
| 대사 | 임금께서 새 글자를 내셨다오. / 이 방을 벽에 붙여야 하오. 거들겠소? | farmer: "벼"는 이렇게 쓴다고? 참 쉽구먼. / 이제 내 억울한 일도 적어 보겠소. bearer: "가마"가 두 글자면 되는구먼. / 어깨 쉴 때 한번 써 봐야겠소. elder: 허허, 소리 나는 대로 적힌다니. / 한 번 읽어나 봅시다. | 풀이를 다 써서 책이 되었다오. / 책장을 실로 꿰어 묶겠소. 같이 하겠소? |
| 셈 | 방 {all}장 가운데 {n}장을 붙였다. | {all}사람 가운데 {n}사람에게 읽어 주었다. | 구멍 {all}개 가운데 {n}개에 실을 꿰었다. |
| 잘함 / 못함 | 척! 방이 반듯하게 붙었어! / 앗, 풀이 모자라 들떴어! | | 쏙! 실이 꿰어졌어! / 앗, 구멍을 비껴갔어! |

## 인도 아그라 타지마할

붉은 돌을 전하던 이야기를 그날의 일 셋으로 바꾼다. 강가에서 코끼리와 함께 큰 돌을 끌어 올리고, 마당에서 꽃잎 돌을 갈고, 흰 무덤 위에서 그 꽃잎을 박아 돌꽃 한 송이를 피운다.

- `first`: 흰 돌 무덤을 한창 짓는 중이란다. 일꾼들을 도와주렴.
- `ask`(그대로): 돌로 꽃을 피울 수 있을까?
- `gate`: 돌 다듬는 마당(yard), 2단계를 마칠 때까지. 소라: "감독관이 계단을 막고 있어. 일부터 거들자."
- `done`: 코끼리와 큰 돌을 끌고, 꽃잎을 갈고, 돌꽃 한 송이를 박았다.
- `reply`와 `intro`(무굴 사람들 쪽지)는 그대로 둔다.
- 지나갈 때 하는 말 가운데 옛 이야기를 가리키는 둘을 바꾼다. 보석 장수 "어디 보자, 보석 한 알이 비는구나." → "먼 나라에서 온 돌 보고 가시오." 꽃을 박는 장인 "한 알이 모자라는구나" → "홈은 다 팠다. 이제 박기만 하면 돼."
