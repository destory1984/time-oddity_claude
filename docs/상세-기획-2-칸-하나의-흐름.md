# Time Oddity — 시간 한량: 상세 기획 2, 칸 하나의 흐름

- 쓴 날: 2026.10.7
- 바탕: `상세-기획-1.md` 1절의 가정 다섯 걸음, 화면 어림 2번과 3번(`mock-screens.html`), 다이얼 시험판, `하늘-계산-확인.md`
- 다루는 것: 수첩에서 "가기"를 누른 때부터 그 칸을 떠날 때까지, 화면이 몇 초에 무엇을 하는가
- 이 문서의 초와 픽셀은 모두 처음 잡아 본 값이다. 첫 토막에서 손으로 해 보고 고친다. 본보기는 칸 64 수정궁이다.

## 1. 한눈에

120칸이 모두 이 틀 하나를 쓴다.

| 마디 | 하는 일 | 채워지는 것 | 걸리는 때 |
|---|---|---|---:|
| 가 | 가기와 내려앉기 | | 20초 |
| 나 | 도착. 땅 그림이 선다 | **날** | 15초 |
| 다 | 하늘을 올려다본다 | **하늘** | 15초 |
| 라 | 오늘로 돌린다 | **남은 것** | 15초 |
| 마 | 이야기 카드와 문제 (하지 않아도 됨) | | 40초 |
| 바 | 사진과 엽서 (하지 않아도 됨) | | 20초 |
| 사 | 떠난다 | | 5초 |

- 다 하면 2분 10초다. 가 → 라만 하면 1분 5초다. 120칸이면 2시간 10분 → 4시간 20분이다. 1권은 한 칸에 2.5분꼴이었다.
- 나, 다, 라는 차례가 없다. 내려앉은 뒤에는 어느 것부터 해도 된다. 마와 바도 내려앉은 뒤 언제든 할 수 있다.
- 칸 셋(날, 하늘, 남은 것)이 다 차면 그 줄이 "채운 칸"이 된다. 카드, 문제, 사진은 세지 않는다.

## 2. 화면의 자리

휴대전화 세로 375 × 812 기준이다. 화면 어림 2번과 같다.

| 자리 | 있는 것 |
|---|---|
| 맨 위 한 줄 | 수첩 단추, 진행("64/120"), 이 칸의 동그라미 셋 |
| 위 가운데 | 날짜(크게)와 자리 이름(작게) |
| 오른쪽 위 | "오늘로" 단추. 오늘에 있을 때는 "그날로" |
| 가운데 | 땅 그림과 하늘. 소라와 말풍선 |
| 왼쪽 아래 | 화면 메모 종이쪽. 그 아래에 "이야기 카드", "맞혀 보렴" |
| 오른쪽 아래 | 사진 단추, "떠나기" 단추 |
| 맨 아래 140픽셀 | 해 다이얼 |

손가락이 부딪치지 않게 자리와 방향으로 가른다.

- 맨 아래 140픽셀에서 옆으로 미는 것은 다이얼이다.
- 그 위에서 위아래로 미는 것은 하늘 보기다.
- 땅에 내려앉아 있는 동안에는 조이스틱과 "전진", "정지"를 숨긴다. "떠나기"를 누르면 다시 나온다.

## 3. 마디마다

### 가. 가기와 내려앉기

| 때 | 일어나는 일 |
|---|---|
| 0.0초 | 수첩이 닫힌다 |
| 0.0 → 1.0초 | 지구가 돌아 그 자리가 화면 가운데로 온다 |
| 1.0 → 2.0초 | 해 다이얼이 드드득 굴러 그 해에 선다. 날짜가 그날로 걸린다 |
| 2.0초 | 그 자리가 금색으로 빛난다. 소라는 그 위 하늘에 떠 있다 |
| 2 → 20초 | 손으로 날아 내려간다. 가까워지면 저절로 느려지고 "내려앉기"가 빛난다 |

- 한 번 가 본 칸은 2.0초에서 곧바로 "나"로 넘어간다(정함, 2026.10.7).
- 수첩을 거치지 않고 지구 위를 날다가 그 자리에 내려앉아도 같다. 다이얼이 그 해에 있지 않으면 땅 그림 없이 지평선과 하늘만 뜨고(4절), 다이얼을 그 해로 굴리면 "나"가 시작된다.

### 나. 도착

내려앉는 때를 0초로 센다.

| 때 | 일어나는 일 | 소리 |
|---|---|---|
| 0.0 → 0.8초 | 땅 그림이 선다. 종이 석 장(먼 것, 가운데, 가까운 것)이 0.2초씩 틈을 두고 아래에서 올라온다 | 종이 스치는 소리 셋 |
| 0.8초 | 하늘이 그날 그 시각의 빛으로 물든다. 하늘은 처음부터 계산된 것이라 달과 별은 이미 제자리에 있다 | |
| 1.0초 | 맨 위의 첫 동그라미가 채워진다. **날** | 낮은 도장 소리 |
| 1.2 → 1.5초 | 화면 메모 종이쪽이 왼쪽에서 밀려 들어온다. "만국박람회 열림. 유리로 지은 집." | |
| 2.5초 | 소라의 말풍선. "유리로 지은 집이다. 반짝반짝." 4초 뒤 사라진다 | |
| 3.0초 | "이야기 카드", "맞혀 보렴", 사진 단추가 나타난다 | |
| 9.0초 | 아직 하늘을 안 봤으면 화면 위 가장자리가 옅게 빛난다 | |
| 15.0초 | 아직 오늘로 안 돌렸으면 "오늘로"가 옅게 빛난다 | |

- 글은 메모 한 줄과 소라 한마디뿐이다. 안내 글은 첫 칸과 두 번째 칸에만 나온다.
- 9초와 15초의 빛은 재촉이 아니라 귀띔이다. 깜빡이지 않고 한 번 밝아졌다 가라앉는다.

### 다. 하늘 보기

| 때 | 일어나는 일 | 소리 |
|---|---|---|
| 손가락을 위로 민다 | 손가락을 따라 시선이 올라간다. 땅 그림이 아래로 밀려 화면 아래 15%에 띠로 남는다 | |
| 끝까지 민 뒤 1.0초 | 달과 맨눈 행성 옆에 이름이 옅게 뜬다 | |
| 1.5초 | 둘째 동그라미가 채워진다. **하늘** | 맑은 종 한 번 |
| 2.0초 | 메모 종이쪽의 "그날 달은"에 계산한 달 모양이 그려진다 | |
| 손가락을 아래로 민다 | 시선이 내려온다 | |

**낮에 일어난 사건.** 120칸 가운데 많은 수가 낮의 사건이다. 낮 하늘에는 볼 것이 없다. 그래서 이렇게 한다.

- 올려다본 채 1.5초가 지나면 시각이 그날 밤 9시로 흘러간다. 2.0초에 걸쳐 해가 지고 별이 돋는다. 그 뒤에 하늘 칸이 채워진다.
- 날짜 아래에 "그날 밤 9시"라고 뜬다. 시선을 내리면 2.0초에 걸쳐 사건의 시각으로 돌아온다.
- 하늘이 사건인 칸은 시각을 옮기지 않는다. 일식(7, 86), 낮에 보인 손님별(22), 금성 일면통과(52), 월식(39)이 그렇다.
- 수정궁은 삭이라 밤 9시에도 달이 없다. 메모에 "그날 달은 없음"이 그려지고, 별과 행성만 보인다.

### 라. 오늘로

이 게임의 간판 장면이다. 가장 공들일 곳이다.

| 때 | 일어나는 일 | 소리 |
|---|---|---|
| 0.0초 | "오늘로"를 누른다 | |
| 0.0 → 3.0초 | 다이얼이 오늘까지 구른다. 처음 0.5초에 빨라지고 마지막 1.0초에 느려진다. 날짜의 해가 따라 넘어간다 | 눈금 소리. 빠를 때는 한데 뭉쳐 낮게 |
| 0.6 → 2.4초 | 땅 그림이 그때에서 오늘로 녹아 바뀐다. 구도는 그대로다 | |
| 0.0 → 3.0초 | 별은 제자리에 있다. 달과 행성은 30%로 흐려진다. 해마다 자리가 달라 3초 안에 수백 번 튀기 때문이다 | |
| 3.0초 | 다이얼이 오늘에 선다. 달과 행성이 오늘의 자리에서 0.4초에 걸쳐 돌아온다 | 마지막 눈금 소리 하나, 또렷하게 |
| 3.3초 | 셋째 동그라미가 채워진다. **남은 것** | 종이 넘기는 소리 |
| 3.5초 | 메모 종이쪽이 뒤집힌다. "남은 것: 없음. 잔디밭뿐." | |
| 4.5초 | 소라의 말풍선. "없어졌네. 옮겨 갔대." | |

- 굴러가는 때는 몇 해를 건너든 3.0초로 묶는다. 1851년에서도, 기원전 2560년에서도 같다.
- 단추가 "그날로"로 바뀐다. 누르면 1.5초에 걸쳐 거꾸로 돌아간다. 돌아갈 때는 칸이 채워지지 않는다.
- 단추를 쓰지 않고 다이얼을 손으로 굴려 오늘까지 가도 같다. 1851 → 2026은 175칸, 2,100픽셀이라 다섯 번쯤 굴려야 한다. 먼 시대는 손으로 못 가니 단추가 있어야 한다.
- 수천 년을 건널 때는 별도 민다. 기원전 2560년에서 오늘로 오면 북극 둘레의 별이 눈에 띄게 돈다(세차운동). 이것은 흐리지 않고 그대로 보여 준다.

### 마. 이야기 카드와 문제

- "이야기 카드"를 누르면 아래에서 카드가 올라와 화면의 아래 절반을 덮는다(0.3초). 세 문장이다. 카드 밖을 누르면 내려간다.
- "맞혀 보렴"을 누르면 문제 한 줄과 답 셋이 뜬다. 맞으면 카드 모서리에 도장이 찍힌다. 틀리면 그 답만 흐려지고 다시 고른다. 벌은 없다.
- 카드를 읽지 않고도 문제를 풀 수 있다. 답은 카드 안의 말에 있다.

### 바. 사진과 엽서

| 때 | 일어나는 일 |
|---|---|
| 사진 단추를 누른다 | 엽서 비율(3:2)의 틀이 뜬다. 틀 밖은 어두워진다 |
| 위아래로 민다 | 틀이 땅과 하늘 사이를 오르내린다. 땅을 많이 넣을지 하늘을 많이 넣을지 고른다 |
| 셔터를 누른다 | 0.1초 번쩍. 사진이 엽서가 되어 0.5초에 걸쳐 수첩 단추로 날아 들어간다 |

- 엽서는 칸마다 한 장만 남는다. 다시 찍으면 바뀐다.
- 그때에서도, 오늘에서도 찍을 수 있다. 엽서 소인에 날짜가 찍힌다.
- 보내기는 수첩의 엽서 갈래에서 한다. 답장은 다음 날 온다. 이 문서는 거기까지 다루지 않는다.

### 사. 떠나기

- "떠나기"를 누르면 땅 그림의 종이 석 장이 0.6초에 걸쳐 아래로 내려가고, 소라가 그 자리의 하늘 위로 떠오른다. 조이스틱이 다시 나온다.
- 수첩 단추를 눌러 다른 칸의 "가기"를 누르면 떠나기를 거치지 않고 바로 간다.

## 4. 그 해가 아닐 때의 땅

땅 그림은 칸마다 두 장뿐이다. 그때와 오늘. 다이얼을 그 사이의 해에 세우면 보여 줄 그림이 없다.

| 다이얼이 선 해 | 땅의 모습 |
|---|---|
| 사건의 해 | 그때 그림 |
| 올해 | 오늘 그림 |
| 그 밖의 해 | 지평선의 윤곽만. 오늘 그림을 한 가지 색으로 눌러 실루엣으로 쓴다. 메모 자리에는 "이 해는 적어 둔 게 없구나"가 뜬다 |

- 하늘은 어느 해든 계산해서 보여 준다. 그림이 없는 해에도 달과 별은 맞다. 기획서 7절의 "사건이 없는 날이면 그 자리의 지형과 그날 하늘만 있다. 그것도 구경이다"가 이것이다.
- 사건의 해에 걸리는 폭은 앞뒤 0년이다. 다이얼 한 칸이 1년이라 꼭 그 눈금에 서야 한다. 시험판에서 사건의 해에 가볍게 걸리게 해 두었다.
- 기획서 7절은 "1851년에 수정궁이 섰다가 사라지는 것을 한 자리에서 본다"고 했다. 그림 두 장으로는 "언제" 사라졌는지를 보여 줄 수 없다. 칸마다 "바뀐 해"를 하나씩 적어 두면 되지만(수정궁은 1852), 120칸의 사실 확인이 더 든다. 첫 토막에는 넣지 않는다.

## 4.1 다이얼의 표시 (2026.10.7에 더함)

사용자가 첫 토막의 다이얼을 굴려 보고 말했다. "뭐가 있는지 모르니까, 계속 돌리기만 해... 뭐가 있으면, 있다가 마킹을 좀 해줘", "우린 역사학자를 대상으로 하는게 아니라구". 그래서 볼 것이 있는 해를 다이얼에 표시한다.

| 무엇 | 어떻게 |
|---|---|
| 볼 것이 있는 해 | 눈금이 금색으로 굵어지고, 그 위에 금색 구슬과 이름이 붙는다. 땅에서는 "그날"과 "오늘" 둘이고, 지구 위에서는 칸의 이름들과 "오늘"이다 |
| 화면 밖에 있을 때 | 다이얼의 왼쪽과 오른쪽 끝에 "◀ 그날", "오늘 ▶" 같은 금색 딱지가 뜬다. 그쪽으로 가장 가까운 것 하나씩이다 |
| 눌러서 가기 | 다이얼의 왼쪽이나 오른쪽 3분의 1을 톡 누르면 그쪽의 표시된 해로 저절로 굴러간다. 오늘까지는 3.0초, 그 밖에는 1.5초다 |
| 가까이 서면 | 표시된 해에서 2칸 안에 멈추면 그 해로 끌려가 선다. 빠르게 지나갈 때는 걸리지 않는다 |

- 플레이어가 연도를 알아야 갈 수 있는 조작은 두지 않는다. 이것은 다이얼뿐 아니라 지구본, 수첩, 하늘에도 같다.

## 5. 소리

| 때 | 소리 |
|---|---|
| 다이얼 눈금 | 시험판의 것. 중심 1,200Hz, 10칸째는 760Hz |
| 땅 그림이 설 때 | 종이 스치는 소리 셋 |
| 날 칸 | 낮은 도장 소리 |
| 하늘 칸 | 맑은 종 한 번 |
| 남은 것 칸 | 종이 넘기는 소리 |
| 셋이 다 찼을 때 | 위 세 소리가 0.15초 틈으로 이어 나고, 수첩의 그 줄에 도장이 찍힌다 |

소리는 사용자가 귀로 듣고 정해야 한다. 이 표는 무엇이 언제 나는지만 정한다.

## 6. 정해 주어야 하는 것

| 번 | 물음 | 지금 생각 |
|---:|---|---|
| 1 | 낮의 사건에서 올려다보면 그날 밤 9시로 시각이 흘러가는가 | 그렇게 한다. 낮 하늘에는 볼 것이 없다 |
| 2 | 사건의 해도 올해도 아닌 해에는 땅을 실루엣으로만 보여 주는가 | 그렇게 한다. 그림이 두 장뿐이다 |
| 3 | "오늘로"가 굴러가는 때를 몇 해든 3초로 묶는가 | 묶는다. 첫 토막에서 2초, 3초, 4초를 견주어 본다 |
| 4 | 내려앉아 있는 동안 조이스틱을 숨기는가 | 숨긴다. 다이얼과 하늘 보기에 손가락을 내어 준다 |
| 5 | 한 칸에 2분 10초가 알맞은가 | 알맞다고 본다. 1권의 2.5분보다 조금 짧다 |

다섯 모두 첫 토막을 손으로 만져 보면 답이 나온다. 지금 정하지 않아도 만들기 시작할 수 있다.
